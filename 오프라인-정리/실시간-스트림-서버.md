## `RTSP`를 이용한 실시간 스트림 서버
![image](https://github.com/user-attachments/assets/ea795d45-aa47-46f6-9984-9edf31efb012)

### 용어 학습
#### 1. RTSP
> Real Time Streaming Protocol

- 스트리밍 세션을 제어하기 위한 프로토콜 (전송 자체는 RTP가 담당)
- **RTSP (Real Time Streaming Protocol)**는 실시간 미디어 스트리밍을 제어하기 위한 네트워크 프로토콜
  - 주로 IP 카메라, CCTV, 방송 시스템, 미디어 서버 등에서 사용되며, 영상이나 오디오 스트리밍을 재생, 일시정지, 중지하는 등의 `제어 명령`


```
[Client] <---- RTSP ----> [Server]
             (Control Channel)
```


- 예시 RTSP URL: `rtsp://192.168.0.100:554/live/stream1`
- 최근에는 `RTMP, HLS, WebRTC` 등의 프로토콜이 RTSP를 대체하거나 보완

#### 2. 스트리밍
> 데이터를 다운로드 완료를 기다리지 않고, 조금씩 받아서 바로 재생하는 방식

![image](https://github.com/user-attachments/assets/bb676757-aeed-4849-b2b7-22b66e03e571)


```
스트리밍 동작 방식

[카메라 or 서버] --(데이터 전송)--> [클라이언트(브라우저/앱)]
                       ↑
                   RTSP/HTTP 등으로 재생 제어
```

- 스트리밍 핵심 개념
- 데이터를 "파일처럼" 저장하지 않고 "재생 가능한 만큼만" 받아서, "실시간 또는 지연된" 상태로 보여주는 방식입니다.
- 즉, “스트리밍”은 미디어 데이터를 실시간으로 전달하고 소비하는 방식

### 동작 방식
1. GStreamer로 만든 실시간 화면 송출 서버 개발
2. 클라이언트에서는 툴을 이용해 해당 송출 서버 RTSP를 통해 통신
3. 결과적으로 클라이언트에서는 실시간 화면을 볼 수 있게 됨
